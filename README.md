# Wisdom Project: AI Questions and Answers

Helping create synthetic persons with wisdom.

## Purpose

This repository is dedicated to identifying and answering the most important questions regarding AI, with a particular focus on alignment, ethics, and the role of AI in human society.

## Project Phases

1. **Identifying the Right Questions**  
   - Collaborators submit AI-related questions via pull requests.  
   - LLMs can assist in refining and expanding the list.  
   - Peer review helps ensure clarity and relevance.  

2. **Providing Answers**  
   - Best and worst answers are submitted and categorized via pull requests.  
   - Peer review ensures quality and diverse perspectives.  

3. **LLM Post-Training & Alignment Testing**  
   - Post-training experiments refine LLM behavior based on categorized answers.  
   - Existing LLM models are tested against the curated knowledge.  

## How to Contribute

1. Fork the repository.
2. Submit a question or an answer via a pull request.
3. Use structured JSON formats for data where applicable.
4. Use environment variables to configure testing scripts.
5. A `Makefile` is available to automate common tasks.

## Goals

- Ensure AI systems are trained with the right questions and best possible answers.
- Analyze and categorize best and worst responses for improved alignment.
- Create a framework for LLM testing and fine-tuning.
